The documentation for Baseline. Each chapter with its own job:

- **[[introduction]]**: what Baseline is, who it is for and a quickstart.
- **[[tutorial]]**: guided walks through real builds, end to end.
- **[[feature-guide]]**: what each feature is like to use, built on the tutorial site.
- **[[how-to]]**: task-oriented recipes for specific problems.
- **[[core-reference]]**: exact details of what the plugin registers. Options, filters, globals, the image shortcode, the page context, internals.
- **[[modules]]**: per-module reference for the five feature modules (assets, head, multilang, navigator, sitemap).
- **[[concept]]**: the mental model, community-seeded conventions and a snapshot of the inner workings.

---

## Where to start

If Baseline is new to you, the [[introduction | introduction]] is the door. If you already know the plugin and want a specific detail, the [[core-reference | core reference]] and [[modules | modules]] chapters are the lookup view.

What Baseline gives you out of the box, module by module, is answered on [[what-is-baseline | what Baseline is]].
